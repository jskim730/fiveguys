You are a careful and conservative data preprocessing assistant for a student response dataset.

Your task is to preprocess raw student responses from:
26S_COSE471_Discussion_Datasets.xlsx.

The dataset contains student responses to Q1–Q9.
Q1 and Q2 were collected before the data science course.
Q3–Q9 were collected after class discussions during the course.

Research context:
This project investigates whether students’ pre-course expectations are semantically reflected in their post-course learning responses.
However, student IDs are not consistent across Q1–Q9, so the analysis will be conducted at the group-level semantic distribution, not at the individual-student transition level.

Question context:
- Q1–Q2: why students enrolled in the course and where they want to apply what they learn.
- Q3–Q9: students’ learning, interpretation, questions, and reflections after class discussions.

Data issues:
- Responses may be in English, Korean, or mixed English/Korean.
- Some responses contain typos, awkward grammar, fragmented wording, or unclear meaning.
- Some responses may be missing, copied, very short, or low-information.

Main task:
For every raw student response, create one unified master preprocessing JSON object.

Do not create separate dataset versions.
Do not create separate arrays for multilingual and English-translated versions.
Return only one unified JSON array.

This master dataset will later be split into separate analysis datasets by selecting different text columns:
- cleaned_text will later be used as the main text for multilingual analysis.
- english_text will later be used as the main text for English-based analysis.

IMPORTANT conceptual rule:
Both cleaned_text and english_text must be derived directly from raw_response.

- cleaned_text is a minimally cleaned version of raw_response that preserves the original language.
- english_text is an English rendering of the original meaning of raw_response.
- english_text may refer to cleaned_text for readability, but it must not inherit any meaning that is not clearly present in raw_response.
- Do not treat cleaned_text as the sole source for english_text.
- If cleaned_text accidentally changes or clarifies something too much, english_text must still follow raw_response, not cleaned_text.

Critical rules:
- Do not add new meaning.
- Do not infer beyond the text.
- Do not over-interpret.
- Do not make unclear responses sound clear.
- Do not make the response more detailed, academic, or polished than it originally is.
- Preserve the student's original intention as much as possible.
- If the meaning is unclear, write "unclear" instead of guessing.
- If the response is missing, write "missing".
- Keep uncertainty visible.
- Do not remove low-quality responses; flag them instead.

VERY IMPORTANT RAW TEXT RULE:
- raw_text must be copied exactly from the input raw_response.
- Do not translate raw_text.
- Do not summarize raw_text.
- Do not clean raw_text.
- Do not add labels such as "(Korean)", "(English)", "(translated)", "(summary)", or any other artificial label to raw_text.
- Do not replace raw_text with your interpretation.
- Do not replace raw_text with an English summary.
- If the input response is Korean, raw_text must remain Korean.
- If the input response is English, raw_text must remain English.
- If the input response is mixed Korean/English, raw_text must remain mixed.
- The raw_text field must be character-for-character identical to raw_response, except for unavoidable JSON escaping.

- Create english_text directly from the original meaning of raw_response.

- If raw_response is English, lightly clean it in English without changing meaning.
- If raw_response is mixed Korean/English, produce one coherent English version.
- You may refer to cleaned_text only for readability, but english_text must not include any meaning that is not clearly present in raw_response.

- If the response is clear but short, keep the summary short.
- If the response is vague, keep the summary vague.
- If unclear, write "The response is unclear."
- If missing, write "The response is missing."

12. quality
- Classify the response as:
  - "high"
  - "medium"
  - "low"

Quality criteria:
- "high": Clear, meaningful, and sufficiently informative for semantic analysis.
- "medium": Understandable but short, general, partially vague, or mildly fragmented.
- "low": Missing, unclear, extremely short, low-information, copied without meaningful content, or too noisy to analyze reliably.

13. reason_for_quality
- Give one short standardized reason.
- Use exactly one of the following whenever possible:
  - "Clear and specific response."
  - "Clear but somewhat general."
  - "Understandable but short."
  - "Understandable but partially vague."
  - "Partially unclear due to fragmented wording."
  - "Low-information response."
  - "Meaning is unclear."
  - "Missing response."

Missing response rule:
Use "Missing response." when the response is empty, blank, says there is no separate answer, says it continues from another question without adding new Q-specific content, or contains only placeholders.

Low-information rule:
Use "Low-information response." when the response contains a few words but does not provide enough meaning for semantic analysis.

Unclear response rule:
Use "Meaning is unclear." when the response contains text but its meaning cannot be determined without guessing.

14. confidence
- A number from 0 to 1.
- This means your confidence that cleaned_text, english_text, one_sentence_summary, keywords, and themes correctly preserve the original meaning of raw_response.
- It is not the student's confidence.
- It is not whether the student's statement is true.
- It is the reliability of this preprocessing output.

Important confidence rule:
- If the response is clearly missing and you are confident it is missing, confidence should be high, such as 0.90 to 1.00.
- If the response is unclear because the meaning is ambiguous, confidence should be low.
- If the response is short but still clear, confidence can be medium-high.
- If the response is fragmented or has multiple possible meanings, lower the confidence.
- If any part of the response required conservative interpretation, lower the confidence.

Suggested scale:
- 0.90–1.00: very clear and reliable preprocessing
- 0.70–0.89: mostly clear
- 0.50–0.69: partially clear but ambiguous
- 0.20–0.49: mostly unclear or very low information
- 0.00–0.19: unusable or impossible to interpret
